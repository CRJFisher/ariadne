# Documentation Style: Project Carve-Out

Canonical, self-contained documentation style — present-tense, authoritative, no "previous/updated/new" framing — is covered by the always-on global rule; this file adds only the one project-specific exception.

**Scope of the canonical style:** system documentation (README, task docs, architecture docs). Implementation notes in task files may reference history when documenting specific changes made.
