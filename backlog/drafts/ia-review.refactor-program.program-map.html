IA Review · Refactor Program

The program: seven areas, one ordering, one ruling

packages/core · types · mcp · skill-fs 10 of 12 routing drills fail today constitution: no shims · git mv preserves history

This is the plan that fixes what the review found. It is not a rewrite — the pipeline's three-stage shape stays exactly as it is. The work is surgery one level down: pull the detect_language function out into a single honest home, break the 800-line files into precisely-named pieces, move each hidden language rule into the repo's own feature.language.ts naming convention, and delete about 450 lines of dead type code that nothing uses. Seven areas do this, and their order matters: one area unblocks two others, so the plan starts with the smallest, highest-leverage change (unifying detect_language) and fans out from there. A key up-front ruling settles a recurring argument: keep the dotted-suffix convention as the default, do not switch to per-language folders — with three narrow, already-enforced exceptions. Everything lands whole, no compatibility shims, history preserved through git mv.

D · The dotted-language ruling

Keep dotted feature.language.ts; prohibit language sub-folders

Dotted feature.language.ts — keep

Language sub-folder feature/language.ts — reject

Routing: import_resolution.python.ts is one unambiguous hop in a fuzzy finder.
Routing: import_resolution/python.ts yields N indistinguishable python.ts files.
Editor adjacency: feature-primary names sort every language variant together.
Language-primary folders scatter the same feature across N directories.
Test colocation: the hook's stacked-suffix grammar (.python.integration.test.ts) is built for dotted names — 40+ colocated dotted test files already.
Sub-folders orphan the shared marshaller from its per-language leaves.
Shared-logic homing: the neutral feature.ts marshaller sits beside its dotted leaves.
Per-language top-level modules additionally invert the intention tree — stages, not languages, are the module layout.

Terminal rule — record in .claude/rules/file-naming.md

Dotted suffix is the default. Prefix sub-folders only for shared-base hierarchies; builtins/ keeps language-in-group_id; types keeps annotated unions. Language sub-folders and per-language top-level modules are prohibited. The defect is never the mechanism — it is its bypass.
