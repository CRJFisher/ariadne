TASK-350.3 · design of the classifier as built

The interim classifier keys on a receiver that collapsed to its own caller — and self-narrows as Fix C lands

A Python builtin, check_untyped_attribute_receiver, flags methods reached only as self.<attr>.<method>() where <attr> has no type. Fix C now resolves the typeable receivers out of the classifier's view, leaving the single genuinely out-of-reach self-attribute row that this rule classifies.

1 row in scope · Shape S _set_value · Cython object self.obj Shape I _repr_html_ → TASK-350.4 builtin, not predicate kind = builtin · status wip
Intent

Classify only the genuinely-unreachable self-attribute receiver, never the members that Fixes A–C now resolve. The discriminator is the telltale signature of an untyped self-attribute receiver — principled, not an allowlist — which Fix C makes self-narrowing.

Why self.obj._set_value() fails: the receiver collapses to the caller's own class

When self.<attr> carries no type, the resolver cannot follow the attribute, so it falls back to the enclosing self class and records resolution_failure.reason = member_type_unknown with resolved_receiver_type set to the caller's own class. That file-equality is the signature the builtin keys on.

The resolver falls back to the enclosing self class

With no attribute type to follow, the receiver collapses to the caller's own class. The caller __setitem__ lives in _ScalarAccessIndexer, so the resolver searches for _set_value there.

3

Resolution fails — recording the caller's own class

resolution_failure.reason = member_type_unknown, resolution_count = 0, and partial_info.resolved_receiver_type is a SymbolId for _ScalarAccessIndexer — the caller's class, in the caller's file.

4

The discriminator: receiver-type file equals caller file

The builtin splits the resolved_receiver_type SymbolId's kind:file:line… form and compares its file to caller_file. Equality, gated by reason === member_type_unknown, means the receiver collapsed to its caller — the untyped-attribute signature. The DSL has no op for this cross-field equality, so it must be a builtin.

Why the broad self-attribute shape narrows to a single residual row

Keyed on the raw self.<attr>.<method>() shape, the signature matched ~401 entries in the pandas run 897eeef (captured before Fix C). Fix C promotes self.<attr> = CapWords(...) assignments to typed properties, so those receivers resolve and leave entry-point detection entirely — leaving the single _set_value self-attribute row this rule classifies; Shape I is dispositioned separately.

Why the residual is safe to classify

What stays flagged after Fix C and is safe for this rule is the genuinely-untyped self-attribute receiver: self.obj (a Cython object param, never = Constructor()). The Fix-C-resolved clusters are no longer entry points when the classifier runs, so no allowlist is needed.

Out of scope — Shape I deferred to TASK-350.4

The fixture-injected styler._repr_html_() row is not classified here: its receiver is a bare untyped parameter, so the ref is receiver_kind: identifier + reason: receiver_type_unknown with no resolved_receiver_type to collapse to.

That signal is indistinguishable from the dominant untyped-local-call bucket (~8,500 receiver_type_unknown occurrences), so classifying it would mask thousands of genuine entry points.

Its true root cause — an unindexed test caller, or _repr_html_ as a framework IPython display-protocol method (name-based, like py-dunder-protocol) — is tracked as TASK-350.4.

builtins/check_untyped-attribute-receiver.ts · matcher core 
// Python method reached as self.<attr>.<method>() where <attr> has no type:
// the resolver collapsed the receiver to the caller's own class.
if (!entry_point.file_path.endsWith(".py")) return false;
if (entry_point.kind !== "method") return false;

return entry_point.diagnostics.ariadne_call_refs.some((ref) => {
  const f = ref.resolution_failure;
  if (ref.receiver_kind !== "self_keyword") return false;
  if (ref.resolution_count !== 0) return false;
  if (f?.reason !== "member_type_unknown") return false;  // load-bearing reason gate
  const rt = f.partial_info.resolved_receiver_type;     // SymbolId | undefined
  if (rt === undefined) return false;
  const receiver_file = rt.split(":")[1];  // kind:file:line:col:...:name
  return receiver_file === ref.caller_file;  // collapsed to caller → untyped attr
});
