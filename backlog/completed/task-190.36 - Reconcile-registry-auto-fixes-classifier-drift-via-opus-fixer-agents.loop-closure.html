Self-repair pipeline · classifier drift · closing the loop

Reconcile-registry repairs a drifted classifier, one fixer agent at a time

Ariadne flags functions that look unreachable. Some flags are false alarms — the function IS called, through dynamic dispatch a static analyzer can't follow — so a small "classifier" predicate learns each false-alarm shape and suppresses it. Over time a classifier can start missing cases it once caught (drift). reconcile-registry records those missed cases as evidence; the loop now closes itself, dispatching one opus agent per drifted classifier to repair its predicate. The hard part is a tug-of-war — widen to catch missed cases (recall), but not so wide it silences real unreachable functions the pipeline exists to surface (precision). So each agent asks a fixability question first, then lands every case in one state: captured, referred as a fixable-in-Ariadne bug, or escalated as mis-classified — parking anything too thin to judge as skipped.

Where this link sits in the self-repair chain

Triage publishes regressions; reconcile-registry records drift. The closing link is a classifier-fixer agent: it edits core's check_<group_id>.ts for same-limitation cases, refers a fixable bug to the backlog, and escalates a mis-classified case to classifier-author.

The drift signal is mechanical and already landed; the closing link turns each recorded miss into a repaired predicate — or a routed hand-off — without human hand-editing.

Why the fixer can't just broaden until every case matches

Recall and precision pull in opposite directions. Widening the predicate is tempting — but each widening risks matching real unreachable functions, the true-positives the pipeline exists to surface. The termination condition is the resolution, not a compromise.

The fixer agent's work loop

Each classifier-fixer owns one check_<group_id>.ts. It resolves each case, runs the fixability triage first, then lands every permanent case in captured or mis-classified — parking anything it can't resolve as skipped.

1

Resolve every case to its full entry

Pull each case's full EnrichedEntryPoint — the exact shape the check receives — and persist it to cases/<project>-<entry_index>.json. A pruned run degrades to its excerpt; a case too thin to rule is recorded skipped, never guessed.

Extend the discriminator to the cases' shared shape — never a catch-all. Ship a test both ways: the evidence cases as positive fixtures and a negative guard keeping a known true-positive out; run the check's own vitest green.

4

Mis-classified — a different limitation escalate

Never stretch the predicate over a different pattern — that suppresses true-positives. Record the case's stable member_symbol (file_path, name, kind, start_line) and why, for the human to feed classifier-author.

// entry_index is run-local; a row's identity is the pair.
// NUL joins the parts — it can't appear in a project dir name.
export function drift_dedup_key(project: string, entry_index: number): string {
  return `${project}\0${entry_index}`;
}

// detect_drift_proposals — dedup evidence by (project, entry_index)

  });
}

How the session picks which rules to dispatch, and gates the whole wave (SKILL step 4)
Dispatch set
Registry-derived: every wip rule with drift_detected: true, dispatched when it had an applied proposal this run or no prior well-formed verdicts.json (Globbed across all run roots) accounts for its evidence in cases[]/skipped_cases[]. A crashed wave recovers next invocation.
Per-rule staging
cases/<project>-<entry_index>.json, verdicts.json, and REVIEW.md under ~/.ariadne/reconcile/<run>/classifier-fixer/<group_id>/.
Build & commit
Fixers edit and run their own check's vitest in parallel; the session owns one post-wave pnpm build --filter core + builtins suite. The human commits the check edits; the fixer never writes registry.json.
The riskiest guarantee

The predicate never over-broadens silently. A fixable case goes to the backlog; a case risking true-positive suppression is escalated; a case too thin to rule is skipped — none absorbed. It grows only to cover the same permanent limitation — all else stays human-owned.

Where this converges

Once eval-sets exist (TASK-190.31.1 / .2), the fixer validates its broadened predicate against the rule's eval-set — precision and recall — before acceptance, so buying recall at the cost of precision is caught mechanically, not by the agent's judgment.
