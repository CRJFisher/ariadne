Chosen mechanism — §2

The fix lives one altitude up: indirect_reachability already owns "is this callable reached without a direct call edge?" and has the registries to answer it for methods, closures, and field stores.

The classifier sees only an EnrichedEntryPoint — name, path, diagnostics — and is structurally blind to those reference shapes.

The three real mechanisms to fund

Two are widenings of one reachability module; one is a pair of convention gates in the call-graph producer. All deletions are duplicate per-language builtins subsumed by the language-general arms.

MECH 1

Closure-as-callback reachability

indirect_reachability.ts · closure arm

An anonymous closure is structurally never an entry point. When its definition carries a callback/argument context, mark it reachable — language-general, replacing two TS-only builtins.

a321closure half of b79f−2 builtins
MECH 2

Value / field / argument references

indirect_reachability.ts · value + field arms

Widen the value-reference arm from function to methods and bound methods, and add a field_store_read arm for callables invoked through an object/class field.

b79f57c2dceb dispatch
MECH 3

Runner / benchmark conventions

trace_call_graph.ts · producer gates

No in-repo reference exists — the harness invokes them. Gate #[test]/#[cfg(test)] definitions and ASV time_* benchmarks at the producer, beside the existing test-file gate.

5543fdd5codegen → known-issue

Benefit versus cost — ranking this group

Benefit

  • Removes 59 of 266 false dead-function flags at the source, so they never recur across the 19 projects.
  • Fixes are language-general: one reachability arm covers Rust, Python, and TS where three per-language builtins did before.
  • Net code reduction — two TS builtins and a stored-callback builtin retire as the core arms land.
  • Strictly additive data model (field_store_read reason); no schema bump, fixtures only.

Cost · blast radius

  • Core fix effort 3–5 concentrated in indirect_reachability.ts (load-bearing edit) plus two gates in trace_call_graph.ts.
  • One over-suppression risk: the field-store arm could hide a genuinely-dead function that is merely mentioned — gate it conservatively, cover with a guard test.
  • Consumers unchanged; shrinking the entry-point array upstream is transparent downstream.
  • Interim classifier work is effort 0 beyond authoring wip rows; the codegen residual stays a known-issue, not a fragile predicate.
Funding call

Fund the three core mechanisms (5543, fdd5, a321 first — effort 1, highest rows-per-effort), then b79f/57c2/dceb (effort 3) for the method, field, and dispatch references. Author the cc55 interim rules now as a zero-effort bridge. The 207 class-B rows do not belong to this group — they are credited to import/name/receiver resolution and must not inflate this group's benefit.
