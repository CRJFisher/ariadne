What else this step has to hold true

  • The resolved-plus-failed count per file must equal the call-kind references emitted, asserted in call_resolver.test.ts over four language fixtures and at the Project tier.
  • This step records a pre-epic taxonomy row for angular, rustc, tokio, sqlx, TypeScript, django, pandas, celery, express and mocha.
  • TASK-376.17, TASK-376.13 and TASK-376.18 each report their per-reason deltas against the baseline row this step's landed tree records.
  • The seven-number call-graph fingerprint must stay byte-identical: this step adds diagnostics and moves no call edge.
  • Each reason names an observation the resolver made about its own state, never a classifier's verdict, so a new resolver path extends the enum.
