Split the classification megafile, give call-graph helpers one owner

program → TASK-362 effort M risk low 867 LOC split 4 new files + 2 relocated 6 rows land · 2 hand-offs open

Ariadne reads source code to work out which functions call which, so it can flag the entry points — functions nothing else calls. Its last stage also diagnoses why each candidate looks unreachable, and one file grew to hold far too much: 867 lines named only extract_entry_point_diagnostics.ts, yet secretly housing seven separate jobs — the diagnosis core, a grep index, feature derivation, a JS/TS-only branch, a file-reading async pass, and two stray helpers unrelated to diagnostics. Worse, the MCP server re-implemented two of those helpers, and the copies have already drifted apart on argument count and return type. When something breaks, you find the right code by archaeology, not by its name. This task splits the megafile into single-purpose files, moves the two call-graph helpers to the stage that owns the call graph, and reconciles the duplicated pair into the one signature both callers need.

The one signature both consumers need

The reconciled contract — optional location for the <anonymous@file:line> display, total string return — now lives once in trace_call_graph/build_signature.ts. As built it adopts MCP's superset shape wholesale and drops core's old try/catch: the fields are required types, so a malformed definition surfaces loudly instead of silently returning undefined.

MCP deletes its copy in 362.7 and imports from core. count_tree_size is unified the same way: core returns a bare number (:703) while MCP's returns {resolved, unresolved} (:88) — reconcile to the shape both consumers need.
