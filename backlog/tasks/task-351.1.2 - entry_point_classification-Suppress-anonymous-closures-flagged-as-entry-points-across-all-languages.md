## Description

<!-- SECTION:DESCRIPTION:BEGIN -->

67 anonymous closures (chiefly rust-lang/rust, plus pandas/serde/sqlx/tokio/pytorch) are flagged as entry points. A closure is structurally never a true entry point: it is invoked inline or passed as an argument. `check_higher-order-function-callback` already suppresses this for TypeScript (`detect_language==="typescript" && name==="<anonymous>" && diagnosis==="no-textual-callers"`), but the same fingerprint fires for Rust/Python closures with no coverage. **Core fix:** generalize the anonymous-closure suppression in `classify_entry_points` so the language guard admits Rust and Python anonymous-function symbols, rather than minting per-language builtins. This is the durable deliverable; the interim classifier (sibling node) suppresses the noise meanwhile.
