TASK-362.2 · Information architecture · Stage-1 indexing

Dissolve the index_single_file type-hub — re-home the wire types and the displaced dispatch

program → TASK-362 effort L risk medium ~18 importers re-pointed 4 wire types re-homed widest import churn in core

Ariadne reads source files and works out which functions call which — that map reveals a codebase's entry points. The first stage, index_single_file, does this one file at a time in four passes: query the syntax tree, build scopes, collect definitions, then references. Over time the single file that orchestrates those passes quietly took on three extra jobs it should not hold. It defines the fundamental data shapes — a CaptureNode, the category and entity enums, the ProcessingContext — that roughly eighteen other files reach up to borrow. And it hand-picks each language's helpers by name. That upward borrowing inverts the natural dependency direction: leaves depending on the orchestrator above them. Task 362.2 moves those shapes down to where they are actually built, and replaces the hand-enumerated per-language calls with proper in-folder dispatchers, leaving the orchestrator to only orchestrate.
