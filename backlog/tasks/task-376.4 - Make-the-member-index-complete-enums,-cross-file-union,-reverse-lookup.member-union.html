Make the member index complete: enums, cross-file union, reverse lookup

wave 1 · no dependencies consumers · 376.8 · 376.14 resolve_references/registries/definition.ts 5 acceptance criteria

Ariadne records a type's members only from the file that declares it, so a Rust impl block in another file contributes nothing; this step merges members from every contributing file, tracks which file gave each, and answers inherited-member queries.

The rest of the change

  • ●verify_reverse_indices rebuilds members_by_file from the member index and compares, because a write site that forgets an index makes eviction under-delete in silence.
  • ●members_by_name maps each member name to every type declaring it, which the structural matcher in TASK-376.14 intersects to narrow candidates to one.
  • ●No pipeline stage produces a second file's members until TASK-376.8, so these registry tests drive attach_members directly.
  • ●A Rust struct's field and method sharing one name must leave the method under that name in the member index.
