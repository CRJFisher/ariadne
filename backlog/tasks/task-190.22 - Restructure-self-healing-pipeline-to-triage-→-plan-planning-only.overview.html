TASK-190.22 · self-repair · architecture · restructure · priority high

Restructure the self-healing pipeline to triage → plan (planning-only)

status To Do (epic) sub-tasks done 13 sub-tasks open 6 skills .claude/skills/triage · .claude/skills/plan

Why

The self-healing pipeline finds Ariadne's own resolver bugs by running Ariadne against real repositories and triaging the entry points it gets wrong. The pipeline is two stages — detect, then plan. Fix delivery is a manual, human-driven step, out of pipeline scope.

The contract triage detects entry points, investigates each (tp = real dead code, fp-* = an Ariadne resolver bug with deterministic fault diagnostics), and publishes triage_results. plan reads results across repos, groups false-positives by AriadneFaultArea, has opus strategists propose hierarchical size-tiered fix plans, and reconciles them into a plan task-DB. It produces plans; it never mutates code, backlog/, or the classifier registry.
