self-healing pipeline · classifier registry

The classifier registry becomes a permanent-limitations catalog — and gains an agent to author its entries

One file (known_issues/registry.json) does two incompatible jobs: it catalogs patterns static analysis can never resolve, and it suppresses triage cost for bugs Ariadne could fix.

Task 190.30 splits those jobs apart: keep only the genuinely-impossible patterns, move fixable bugs to the backlog, and add a classifier-author agent so new permanent-limitation entries get a real classifier instead of a never-firing stub.
