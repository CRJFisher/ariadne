self-healing pipeline · prioritize skill

Prioritize gains a deep-investigation step: verified design, not the plan's hypothesis

Today prioritize hands the human one thin decision aid built from the plan's row prose — a hypothesis about each fix, never verified against the code.

The change inserts investigation and design: a refactor-investigator reads the real packages/core per change group, a refactor-task-architect derives the backlog split from its grounded verdict — on every group, before funding.

So the human decides with N verified designs in hand; on promotion each funded group's plan and doc graduate into backlog/, split into tasks the investigator validated.

the barrier between 3 and 4

Step 4 reads each group's refactor_plan.md from disk, not from memory — so every step-3 investigation wave must complete before the first step-4 doc is dispatched. The verified plans on disk are the input the rest of the workflow is built on.

02The decision input upgrades from one hypothesis to N verified designs

The point of the change: the human used to decide from one aid summarising the plan's guess; now from one code-grounded refactor design per change group, each having read the real code.

Decide on verified designs

the punchline

The plan strategist trusts the evidence rollup and never reads the cited files front to back — its node bodies are a hypothesis about the fix, not a design. The new step turns that hypothesis into a verified design before a single dollar is funded.

03What one refactor-investigator does per change group

One input (a fault-area change group), reads the real core, one output (a 9-section refactor plan). It is design-only: it reads packages/core but the dashed boundary marks everything it never writes. refactor-investigator.md frontmatter + §Get to grips with the code.

04refactor-task-architect derives the backlog split from the grounded verdict

After investigation, before export, one refactor-task-architect per group reads its plan's §6 sub-task mapping and §7 sequencing and writes a BacklogIdAssignment map. The plan engine's tier labels are a routing concept — the wrong axis; the architect re-derives the split from the grounded verdict. SKILL.md §6a.

Tier-based decomposition

the natural-split criterion

One top-level task for the fundamental refactor; a sub-task only where the investigator identified a genuinely separate downstream adaptation. The plan's original per-leaf split is never re-introduced unless the investigator validated each leaf as an independently addressable change.

05The 347–351 artifacts, now auto-produced and split per funded group

The 347 pair was written by hand; the change makes it a per-group output of prioritize: investigation stages it, the architect's task_assignment.json drives the export ids, and on promotion each funded group's pair graduates into backlog/. SKILL.md §6.

the export flag

export_to_backlog.ts gains --assignments <file>: when supplied, it takes the backlog ids from task_assignment.json and bypasses assign_backlog_ids. Without the flag the script behaves exactly as today, so non-prioritize callers are unaffected.

06The boundary stays clean: plan plans, prioritize designs

No deep design leaks into the plan engine. The plan-strategist stays the cheap router-and-estimator; all new deep design — the investigator and the task architect — lives in prioritize, the stage already licensed to write backlog/.

Why it lands here: the write-capable, human-invoked side of the boundary is the natural home for design that produces backlog artifacts — putting it in the autonomous plan sweep would mean designing fixes nobody chose to fund.

07The cost: every candidate group is investigated before funding

A deliberate, accepted cost — a group the human does not fund is still investigated. Three things keep the spend bounded and worthwhile. SKILL.md §Workflow intro.

bound 1

Fan-out

Bounded by the fault-area count per sweep — a handful of groups, run ≤5 in parallel per wave.

bound 2

Pre-filter

The plan's core_fix_effort estimate already screens out the trivially cheap fixes before they reach investigation.

bound 3

Payoff

The spend buys decision quality on exactly the changes that carry real blast radius.
