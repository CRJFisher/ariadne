Self-repair pipeline · entry-point classification

Finding the codebase's true entry points — and teaching the tool its own false alarms

Ariadne traces call graphs to find a codebase's real entry points. A function with no visible caller looks like an entry point — but many are reached indirectly: stored in a field, passed as a callback, invoked by a framework. Task 190 builds a self-repair pipeline that detects these false alarms, investigates each in its own context, and lands the core fixes so the analysis keeps improving itself. Its two dozen sub-tasks split into a few threads: the triage-then-plan loop that finds and routes false positives, the classifier registry that catalogs the permanently-unresolvable shapes, and the reconcile-registry surface the human uses to keep that catalog honest. Its threads compose into one loop, and each landed fix removes a class of false alarms while retiring the rule that once flagged them.
